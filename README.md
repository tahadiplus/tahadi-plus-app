# Tahadi Plus

وەشانی یەکەمی ئەپی **Tahadi Plus** بە React Native و Expo، ئامادەی تاقیکردنەوە لەسەر iPhone.

## تاقیکردنەوە لەسەر iPhone

1. لە App Store ئەپی **Expo Go** دابەزێنە.
2. لە Windows، Node.js دابمەزرێنە.
3. ئەم ڕیپۆیە Clone بکە:
   ```bash
   git clone https://github.com/tahadiplus/tahadi-plus-app.git
   cd tahadi-plus-app
   ```
4. پێداویستییەکان دابمەزرێنە و ئەپەکە بکەرەوە:
   ```bash
   npm install
   npx expo start
   ```
5. QR code ـەکە بە کامێرای iPhone بسکەنە و بە Expo Go بیکەرەوە.

کۆمپیوتەر و iPhone دەبێت لەسەر هەمان Wi-Fi بن.
