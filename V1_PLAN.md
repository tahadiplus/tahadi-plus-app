# Tahadi Plus — Version 1

## Goal
Ship a playable iPhone-first MVP that gives users a reason to return every day.

## Core loop
1. Open Tahadi Plus.
2. Play Quiz / PK challenge.
3. Earn coins.
4. Complete a daily challenge.
5. Climb the leaderboard.
6. Return the next day.

## V1 features
- Home screen and navigation
- Quiz challenge
- PK / 1v1 challenge
- Team modes UI
- Coin balance
- Coin shop UI
- Profile and stats
- Leaderboard
- Daily challenges and rewards

## Next phase
After retention and gameplay are tested:
- Account/login backend
- Persistent cloud profiles
- Real multiplayer matchmaking
- Friend invitations
- Rewarded ads
- In-app coin purchases
- VIP subscription
- App Store production setup

## Monetization principle
Keep the first experience free. Monetization should be added after the core gameplay is stable, with rewarded ads, optional coin purchases, and VIP benefits rather than blocking basic play.
